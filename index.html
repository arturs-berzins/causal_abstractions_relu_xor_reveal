Solution set of a ReLU network


Solution set $F\subset\mathcal{W}$: all parameters interpolating the data $(X,Y)$.
We can explicitly calculate the entire $F$ for ReLU networks.


Key idea:
  • the path-lifting $\phi : \mathcal{W} \rightarrow \Sigma$ factors a ReLU network as $\mu_X(w) = A_{X,\sigma} \phi(w)$;
  • $\Sigma$ is toric, $A_{X, \sigma}$ is linear;
  • the lifted fiber $\phi(F)$ is a finite union of activation-restricted affine sections of $\Sigma$;
  • $\phi^{-1}(\phi(F))$ is easy-ish.



Caveat:
naively $\mathcal{O}(2^{N n_H})$ with $N$ samples and $n_H$ hidden neurons.

Causal abstractions
Geiger et al. 2025



Proposed foundational basis for mech-interp

Causal models represent and help analyze and predict cause-and-effect relationships within a system.

Causal abstraction describes when a high-level causal model is an abstraction of a low-level causal model.



Equivalence: an invertible transformation of states (and interventions) that preserves causal behavior.

Abstraction: a many-to-one transformation of states (and corresponding interventions) that preserves the high-level causal behavior.

Approximate transformation: a transformation that preserves causal behavior up to a specified error.

Conclusion
  • H1: true in XOR, if we allow for abstractions.
  • H2: false: face inclusion doesn't act as abstraction.
  • The fiber geometry regulates which abstractions are reachable as parameter deformations.
